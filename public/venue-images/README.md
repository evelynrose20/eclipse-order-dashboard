# The Midnight Eclipse — replacing menu images

The venue's dedicated menu automatically displays pictures uploaded into this folder. No React or CSS editing is necessary.

## Upload from your browser

1. Open [this folder on GitHub](https://github.com/evelynrose20/eclipse-order-dashboard/tree/main/public/venue-images).
2. Select **Add file → Upload files** (you must be signed in to an account with repository write access).
3. Rename each original photo on your computer to the **exact filename** below, using lowercase letters and `.jpg`. Export/convert your photo as JPEG first if it is currently PNG or WEBP; changing only the extension will not convert it.
4. Drag the photos into GitHub and select **Commit changes**. When the Pages deployment completes, open [the live menu](https://rosefires.com/venue/menu/) and refresh.

To replace an existing photo, use GitHub's file editor/replacement workflow or remove the old file and upload the new JPG with the same name, then commit. Images are public and visible to everyone visiting the site. Avoid uploading personal/private photos or metadata.

## Photo suggestions

Use a landscape crop roughly 1200 × 800 pixels, JPG, ideally under 400 KB per image for a faster mobile menu. The layout automatically crops each image to fill the card. If an image is missing or misnamed, the existing stylized illustration remains visible.

This is a static-site workflow. Uploading through GitHub updates the public site upon deployment; it does not provide an in-site image uploader or store images in the Windows API.
